Signing this once covers every contribution you ever make to gopdfrab.

You do **not** need to sign anything to open an issue, ask a question, or

Anything you send for inclusion in the project: a pull request, a patch, a
documentation change, a test file you wrote yourself.

a snippet in an issue to illustrate a bug, code from elsewhere you think is
worth a look — write **"Not a Contribution"** next to it. Anything marked that
way is outside this agreement and will not be used in the project.

## How to sign

Open your pull request. A bot will comment on it and ask you to reply with a
single sentence confirming you have read and agree to this document. Post that
comment and the check turns green. It will not ask you again.

The signature is recorded, with your GitHub username, in the `cla-signatures`
branch of this repository.
